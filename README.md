# Mohammed Faisal Hasan - Portfolio

A modern, interactive portfolio showcasing AI Automation & Full Stack Development projects.

## 🚀 Features

- ✨ Modern UI with Framer Motion animations
- 🌗 Dark/Light mode toggle
- 🎨 Particle background with tsParticles
- 📱 Fully responsive design
- 💬 Interactive chatbot (FaisalBot)
- 📰 Blog section with RSS feed integration
- 🎯 Smooth scroll animations

## 🛠️ Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- tsParticles
- Lucide React Icons

## 📦 Installation

```bash
npm install
```

## 🏃 Run Development Server

```bash
npm run dev
```

## 🏗️ Build for Production

```bash
npm run build
```
